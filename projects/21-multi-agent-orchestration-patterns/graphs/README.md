# `graphs/`

| File | What it does |
|---|---|
| [`blackboard.mmd`](blackboard.mmd) | Compiled LangGraph diagram (Mermaid) of the `blackboard` pattern |
| [`concurrent.mmd`](concurrent.mmd) | Compiled LangGraph diagram (Mermaid) of the `concurrent` pattern |
| [`group_chat.mmd`](group_chat.mmd) | Compiled LangGraph diagram (Mermaid) of the `group_chat` pattern |
| [`hierarchical.mmd`](hierarchical.mmd) | Compiled LangGraph diagram (Mermaid) of the `hierarchical` pattern |
| [`magentic.mmd`](magentic.mmd) | Compiled LangGraph diagram (Mermaid) of the `magentic` pattern |
| [`sequential.mmd`](sequential.mmd) | Compiled LangGraph diagram (Mermaid) of the `sequential` pattern |
| [`supervisor.mmd`](supervisor.mmd) | Compiled LangGraph diagram (Mermaid) of the `supervisor` pattern |
| [`swarm.mmd`](swarm.mmd) | Compiled LangGraph diagram (Mermaid) of the `swarm` pattern |
