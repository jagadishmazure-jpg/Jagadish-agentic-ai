# `banks`

One YAML question bank per course module. The file name is the module id. The API serves prompts and choices only.

| File | What it does |
|---|---|
| [`foundations.yaml`](foundations.yaml) | Foundations questions and the token-estimate lab. |
| [`frameworks-orchestration.yaml`](frameworks-orchestration.yaml) | Graphs, routing and orchestration patterns. |
| [`llm-core.yaml`](llm-core.yaml) | Temperature, mocks, fallbacks, context windows. |
| [`rag-stack.yaml`](rag-stack.yaml) | Corrective RAG, citations, ACL and honest misses. |
| [`agentic-core.yaml`](agentic-core.yaml) | Stop conditions, interrupts and the tool gateway. |
| [`trust-quality.yaml`](trust-quality.yaml) | Eval gates, chaos exits, synthetic data, injection. |
| [`customization.yaml`](customization.yaml) | Prompt versus fine-tune, splits and promotion. |
| [`production-deployment.yaml`](production-deployment.yaml) | OIDC, IaC that has not been applied, health and logs. |
